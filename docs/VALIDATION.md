## 已记录的原生验证

Mac 已用隔离数据检查双窗口草稿退出顺序、取消后的继续输入、保存或放弃，以及重启后的已提交任务一致性。Windows 已完成限定单屏的快速新增、真实外部点击、隐藏后保留草稿、固定展开、关闭控制台后常驻及退出重启检查。更早版本的其他验证不能自动算作当前版本全部通过。

浏览器回归和几何算法测试不能替代系统窗口验证。仍需补齐：

- 持续拖动、缩放、完整实体输入与中文输入法组合矩阵。
- 多显示器、混合缩放、负坐标接缝、插拔显示器、睡眠恢复及 Spaces／虚拟桌面。
- 数据恢复中的完整失败矩阵，包括磁盘满、真实断电和事务切换瞬间中断。
- 连续 3–7 天实际使用、支持系统最低版本、完整安装升级与卸载交互。
- Mac Developer ID 签名与公证、Windows 签名和正式分发验证。

多屏项目在本轮内部试用中未作为交付阻断，仍然是未验证项。
