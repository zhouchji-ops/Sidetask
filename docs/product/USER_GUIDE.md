# 侧笺 · SideTask 使用说明书

适用版本：**0.1.0 内部试用版**。更新：2026-09-25。说明依据整合版本及Windows最新收尾修复；菜单和按钮名称按现有界面整理，完整原生与公开分发验收尚未完成。

侧笺有两个界面：**小窗用于随手查看、添加和勾选，大窗用于集中管理和设置**。两者共用本机任务数据，核心使用无需注册账号。Mac 与 Windows 各自保存数据，目前没有云同步。

### Mac

1. 下载并解压，得到 `SideTask.app`。
2. 将 App 放入“应用程序”等固定位置，再打开。
3. 已安装旧版时，先按下方更新步骤导出备份并明确退出，再替换 App。

当前 Mac 包只有临时签名，尚无 Developer ID 签名和公证。系统可能阻止首次打开；遇到拦截时记录完整提示并联系维护者确认分发方式，不需要关闭系统安全检查，也不要删除任务数据来解决启动拦截。

### Windows

1. 解压 GitHub 产物，运行 `SideTask_0.1.0_x64-setup.exe`。
2. 按安装向导完成安装，打开 SideTask。安装器支持简体中文和英文。
3. 若安装器提示缺少运行组件或安装失败，保留完整错误内容，按提示处理或联系维护者。

当前 Windows 包未签名，系统可能出现发布者或安全提示。核对下载来源和包摘要；不能把本手册当成“所有安全提示都可以忽略”的依据。

### 更新、重装和备份

1. 先保存或明确放弃所有草稿，包括小窗快速输入，等保存完成；再到旧版“设置 → 数据备份”导出任务备份，并另行保管。
2. 从菜单栏／托盘选择“退出 SideTask”。若导出后又保存了新内容，应重新导出再退出。仅关闭大窗不算退出。
3. 使用同一平台的新 App 或安装器完成替换／更新，保留原数据目录。
4. 打开新版，核对今日、全部任务、已完成和回收站，再检查小窗位置与设置。

新版会校验已有数据库，必要时先备份再升级。不要靠清空数据目录解决更新问题，也不要手工修改数据库版本来降级。重装应用不能替代备份；跨版本安装和全部故障情况仍在持续验收。

## 第一次使用

首次原生启动是空任务库，无需账号。控制台会说明“关闭控制台后，侧笺仍在运行”；读完可点“知道了”，以后仍能在“设置 → 使用说明”查看。

用下面的流程完成第一项任务：

1. 在控制台点击“新建任务”，填写任务名称，确认“安排到今日”已开启，点击“创建任务”。
2. 点击侧栏“打开边缘小窗”，在上方“今日计划”中找到它。
3. 任务做完后，点击左侧勾选按钮。控制台会同步完成状态。
4. 想再记一件事，直接点小窗“今日计划”旁的＋，输入后点击“添加”或按 Enter。
5. 需要详细编辑，点击任务名称或小窗底部“管理任务”，进入控制台。

任务名称至少需要一个非空字符，最多 240 个字；备注可选，最多 5,000 个字符。只想记录名称时不必设置 DDL。

## 认识两个窗口

### 控制台

| 入口 | 显示什么／用来做什么 |
| --- | --- |
| 今日 | 当天安排的任务、当天已完成，以及“此前未完成”待重新安排的任务 |
| 全部任务 | 默认显示未删除的未完成任务，包括没有 DDL、没有安排到今日的任务 |
| 截止日期 | 有 DDL 的未完成任务，可切换排序 |
| 已完成 | 已完成且未移入回收站的任务 |
| 回收站 | 已移入回收站的任务，可搜索并单项恢复 |
| 设置 | 界面风格、边缘小窗、明暗外观、数据备份和使用说明 |

点击任务名称打开右侧详情。普通搜索会跨日常任务页查询，具体范围见[搜索与回收站](#搜索与回收站)。

### 边缘小窗

上方是“今日计划”，下方是“截止日期”。顶部可拖动位置、保持展开或收起；今日标题旁的＋用于快速添加。底部“管理任务”打开控制台，齿轮打开设置。

小窗折叠后的窄条是“把手”，用于重新展开或拖动。控制台、小窗和把手属于同一应用，不需要分别导入数据。

## 创建与编辑任务

### 在大窗新建

点击“新建任务”，填写“任务名称”，按需设置“截止日期”“具体时间”“重要程度”“备注”，检查“安排到今日”开关，再点击“创建任务”。从“今日”页新建时默认安排到今日，从其他页新建时可自行打开该开关。

第一版每条任务都是独立事项，完成表示整项完成。不支持子任务、任务树和部分完成百分比；备注用于补充说明。

### 在小窗快速添加

点击今日标题旁或小窗底部的＋，输入名称，点击“添加”或按 Enter。新任务以普通重要程度创建、无 DDL，并加入提交时的今日计划；成功后可连续添加。

中文输入法正在选字时，Enter 用于确认候选，不应创建任务。遇到保存失败，输入内容会保留，先查看错误再重试。需要 DDL 或备注时，创建后点击任务名称到控制台补充。

### 修改已有任务

点击任务名称，在右侧修改后点“保存修改”。关闭详情或切换页面时若有草稿，可选择“继续编辑”“保存并离开”或“放弃修改”。

若提示任务已在另一处修改，先核对新状态和当前草稿；确认后可点“保留草稿，基于最新版本保存”，再保存所需修改。不要把冲突提示当作已经保存成功。

## 安排今日与完成任务

### 加入和移出今日

在全部任务或截止日期列表，使用任务旁的“加入今日”按钮；也可以在详情中点击“加入今日”。已安排后会显示今日标识。

移出时使用今日列表的“移出今日”按钮，或在详情点击“已安排”切换。它只取消当天安排，**不删除任务、不改 DDL、不标记完成**。还可以从全部任务找到这项任务。

### 调整今日顺序

在控制台进入“今日”，清空搜索，然后使用未完成任务旁的“上移”“下移”。小窗同步这个顺序。当前通过按钮排序，不支持拖拽任务行排序；今日顺序不改变 DDL 列表的排序。

### 完成和撤销

点击任务左侧的勾选按钮，或在详情点“标记完成”。今日、DDL 和控制台更新同一项任务，DDL 的未完成列表会移除已完成项。

误点后可立即使用提示中的“撤销”；也可进入“已完成”，或展开今日的“已完成”分组，再次点击勾选按钮撤销。今日已完成分组只包含当天安排过的任务，其余到“已完成”页查找。

### 跨天后的任务

跨天不会删除任务、自动完成、修改 DDL 或自动复制到新的一天。最近一次安排在过去、仍未完成且没有今天或更晚安排的任务，会进入“此前未完成”。在控制台逐项加入今日；小窗中的“此前未完成”入口会带你到控制台处理。

如果移出今日后又看到它出现在“此前未完成”，是因为它仍保留着更早的安排记录，不是删除失败。目前界面只提供安排今日的入口，没有选择任意未来计划日期的编辑器。

## 截止日期与重要程度

在新建表单或任务详情设置“截止日期”；选了日期才会出现“具体时间”。

| 设置方式 | 含义 |
| --- | --- |
| 不设日期 | 没有 DDL，仍可安排到今日 |
| 只设日期，时间留空 | 截止于所选日期结束前，之后才算逾期 |
| 日期和时间都填写 | 精确到对应时刻，从该时刻起算逾期 |
| 清空日期并保存 | 移除 DDL，也清除对应时间，任务本身保留 |

新设 DDL 会固定当时使用的时区，界面显示时区说明。旧数据可能提示随系统时区解释；实际修改它的截止字段后才固定时区，仅修改标题或备注不会悄悄改变其时间含义。夏令时导致不存在或有歧义的时间会被拒绝，保留草稿供调整。

“重要程度”可选高、普通、低。截止列表默认按日期排序，可通过“日期／重要程度”排序入口切换；重要程度模式下先高后低，同级再按截止时间。小窗和控制台使用同一排序偏好。

例如：报告 9 月 30 日截止，9 月 25 日加入今日，DDL 仍是 9 月 30 日。今天只做了一部分时保持未完成；整项做完才勾选。**DDL 是截止信息，当前不会主动弹出到期提醒。**

## 使用边缘小窗

### 展开、收起与保持展开

默认“单击展开”：点击把手打开，点击其他位置收起。Mac与Windows均观察真实外点；单纯切换焦点不收起。输入期间外点可以隐藏小窗，再次展开仍保留未提交的文字。固定展开、拖动、缩放和退出确认期间有相应保护。

顶部图钉“保持展开”可暂停自动收起，再点“取消保持展开”恢复。顶部叉号“收起小窗”会收起并解除保持展开。保持展开不会锁住位置，仍可调整停靠。

若选择“悬停展开”，停留在把手区域后展开，离开后按设置延迟收起。正在输入、处理应用内确认弹窗、拖动、缩放或处理退出确认时有交互保护；控制台处于前台编辑时，也会限制非固定小窗的自动呼出。

### 移动与调整尺寸

- **位置：**拖动收起的把手或展开后的标题拖动区。不要从任务文字或勾选按钮开始拖动。
- **换边：**可在设置选择左侧／右侧；原生拖动也提供换边或主动换屏后的重新停靠路径，实际可用范围以当前设备验证为准。
- **尺寸：**拖动小窗边角的尺寸控件，或到设置填写宽高。松手后保存，调整中可用 Esc 取消。
- **两区比例：**拖动今日与截止日期之间的分隔条，松手后保存；今日占比范围为 30%–70%。

尺寸和位置会按当前屏幕可用空间约束。混合 DPI、多屏接缝、拔插、睡眠与全屏空间仍在完整原生验收中；遇到偏移先从控制台恢复小窗，必要时重新设置停靠，不要以反复强制退出替代保存草稿。

### 隐藏后继续输入

普通隐藏后重新展开，小窗未保存文字仍在。点击输入框自己的“收起添加任务”叉号，有文字时可选“保存并收起”“放弃草稿”“继续编辑”；保存失败也不会清空输入。草稿只在本次应用运行期间保留，**不是自动保存的任务，不能保证崩溃或强制结束后找回**。

## 外观与窗口设置

在控制台点击“设置”，或点击小窗底部齿轮。

| 设置 | 操作方式与保存规则 |
| --- | --- |
| 界面风格 | 纸笺、霜序、暖刊、极简；点选后立即保存并同步大小窗与把手 |
| 启用边缘入口 | 开关边缘把手；改动后点击“保存设置” |
| 停靠位置 | 选择左侧／右侧，再保存 |
| 小窗尺寸 | 宽 300–640、高 380–1000，按可用工作区调整；填完保存 |
| 小窗展开方式 | 单击展开／悬停展开，选择后保存；默认单击 |
| 展开延迟／收起延迟 | 仅悬停模式显示；单位 ms，展开 0–1500、收起 100–2500，保存后生效 |
| 保持小窗展开 | 暂停自动收起，仍可移动；设置页修改后保存 |
| 外观 | 浅色、深色或跟随系统，选择后点击“保存设置” |

四套风格与明暗是独立选择。换风格不会重置任务，也不会替你保存其他未提交设置。停靠、模式和明暗等修改需点底部“保存设置”，不要只切换选项就离开。

若显示“设置已保存，但窗口尚未生效”，点击“重试应用窗口设置”；只有写入成功不等于系统窗口已调整成功。设置冲突时会保留草稿；核对后再选择“确认以我的设置草稿覆盖”并保存。

控制台的普通位置、尺寸与最大化偏好会尝试记忆。出现“本次窗口位置未保存”时，可“重试保存位置”或“不保存本次位置”；这不表示任务数据丢失，无需为此恢复整份数据库。

## 搜索与回收站

### 搜索任务

控制台顶部搜索框按标题和备注查找。普通搜索覆盖未删除的未完成与已完成任务，**不受当前“今日／全部任务／截止日期”等页面范围限制**；清空搜索恢复当前页列表。

进入回收站后，搜索仅查询回收站中的任务。普通搜索不会显示已移入回收站的项目。

### 移入与恢复

在任务详情点击“移入回收站”。有未保存修改时，可“继续编辑”“保存后移入”或“放弃修改并移入”。

进入侧栏“回收站”，找到任务后使用恢复按钮，或在详情点击“恢复此任务”。恢复保留原 ID、备注、DDL、完成状态和所有日期的计划；已完成任务恢复后仍已完成，旧日期计划不会自动变成今天的安排。

当前没有永久删除、清空回收站、自动过期清理或批量删除。想取消今天的安排应使用“移出今日”，不用将任务移入回收站。

## 备份与恢复

### 导出任务备份

1. 先保存或放弃各处未提交修改，等保存结束。
2. 打开“设置 → 数据备份”，点击“导出任务备份”。
3. 查看界面返回的完整文件路径。原生版直接写入数据目录的 `exports/SideTask-<UUID>.json`，没有另选保存位置的对话框。
4. 将这个 JSON 另行复制到自己管理的备份位置。

备份包含全部任务、回收站和所有日期的计划，不包含本机风格、停靠或控制台位置。当前无定时备份和云备份，导出文件需要自己保管。

### 从 JSON 恢复任务

**这是替换，不是合并。恢复后任务集合会回到备份内容，当前新增而备份中没有的任务不会继续留在任务列表。**

1. 先保存或明确放弃所有草稿，包括小窗快速输入，等保存完成；再导出并保管当前任务。
2. 点击“选择备份恢复”，选择合法 JSON。
3. 核对预览中的任务数、其中回收站数量、计划数和导出时间。
4. 确认需要替换后，点击“备份当前数据并恢复”。应用先创建完整 SQLite 安全备份，成功后再替换任务和计划。
5. 记录成功提示里的安全备份路径，核对任务；本机风格、窗口设置和停靠位置保留。

可导入合法 v1／v2 备份，当前导出为 v2；上限为 10 MiB、10,000 项任务、100,000 条计划，回收站也计入。若提示预览后数据发生变化，取消并重新选择文件、重新核对；校验或安全备份失败时不执行替换。

### 启动时进入数据恢复界面

如果数据库无法正常打开，会显示“需要恢复本地数据”，任务暂不加载：

1. 查看故障说明，必要时展开“查看启动检查错误”，或点击“重新检查备份”。
2. 在“可用备份”核对文件修改时间、任务／计划数、备份类型和文件名，选中所需副本，点击“检查并恢复所选备份”。
3. 确认页可“返回选择”；确定后点“保留原文件并恢复”。
4. 成功后记录原数据库及日志的保留目录，点击“重新启动侧笺”。

这里使用的是**完整 SQLite 副本**，会恢复副本中的本机设置；与上面的 JSON 任务恢复不同。备份之后的修改不会出现在恢复后的任务中，原始文件另行保留。无候选时页面会显示数据目录；没有候选、只有 JSON、磁盘空间不足或持续失败时，按[详细故障恢复说明](../engineering/DATA_RECOVERY.md)操作或联系维护者。不要将 JSON 改名为数据库，也不要直接删除原库或恢复标记。

恢复界面不会创建托盘和小窗；关闭这个恢复窗口会请求退出，不适用普通控制台“关闭仅隐藏”的规则。

### 数据存在哪里

| 平台 | 原生版数据目录 |
| --- | --- |
| Mac | `~/Library/Application Support/com.changjin.sidetask/` |
| Windows | `%APPDATA%\com.changjin.sidetask\` |

正在使用的数据库名为 `sidetask.sqlite3`。普通用户优先使用应用内导出；运行时只复制这个主文件可能遗漏已提交日志。需要离线保留时，先明确退出所有 SideTask 进程，再按照详细恢复说明保留整个目录及日志，不混用不同副本的文件。

## 关闭退出与键盘操作

| 动作 | 结果 |
| --- | --- |
| 关闭控制台窗口 | 直接隐藏大窗，未保存草稿留在当前窗口内存，应用和边缘入口继续运行 |
| 小窗顶部“收起小窗” | 收起小窗并解除保持展开，不退出应用 |
| 从菜单栏／托盘选择“打开侧笺” | 回到已有应用和任务，不创建另一份数据；Windows 也可左击托盘图标 |
| 选择“退出 SideTask” | 处理小窗及控制台草稿后结束整个应用 |

菜单栏／托盘还提供“显示 / 收起小窗”“设置…”。退出时可能先处理小窗草稿，选择“取消退出”“放弃并继续退出”或“保存并继续退出”；随后控制台草稿提供“取消退出”“放弃并退出”“保存并退出”。取消会停止退出并保留尚未处理的草稿；此前明确保存或放弃的操作不会撤销。保存失败也不会当作已保存继续退出。强制结束进程不等于正常退出。

下列是**应用内操作**，不是在任何程序中都能呼出的全局快捷键：

| 按键 | 使用位置与作用 |
| --- | --- |
| Mac `⌘N`／Windows `Ctrl+N` | 控制台内打开新建任务；保存、确认弹层或输入法组合期间可能暂不响应 |
| `/` | 控制台中，未在输入框或弹层输入时聚焦搜索 |
| `Enter` | 小窗快速添加提交名称；中文组合输入确认期间不提交 |
| `Esc` | 取消当前可取消弹层或调整；涉及草稿时按提示处理，保存进行中不会强行关闭 |
| `↑`／`↓` | 聚焦小窗分隔条时每次调整 5%，松开保存；左右键不调整分区 |
| 四个方向键 | 聚焦尺寸控件时每次调整 10 逻辑像素，松开保存；向屏幕内部方向增宽，`↓` 增高、`↑` 减高 |
| Mac `⌘Q` | 进入正常应用退出及草稿处理流程 |

键盘与真实原生输入法、焦点和手势在不同平台的完整组合仍在验收。若快捷键未响应，可使用对应可见按钮，并记录当时焦点与操作场景。

## 常见问题

| 问题 | 先这样处理 |
| --- | --- |
| 关闭大窗后程序怎么还在？ | 这是常驻设计。菜单栏／托盘可恢复；要结束进程，选择“退出 SideTask” |
| 找不到边缘把手或小窗 | 从菜单栏／托盘恢复控制台，检查“启用边缘入口”并保存，再点“打开边缘小窗”；若有窗口设置错误，先重试应用设置 |
| 鼠标移过去没有展开 | 默认单击模式，需要点把手；想用悬停，在设置中主动选择并保存 |
| 点击外部没有收起 | 检查是否保持展开、拖动／缩放／退出确认中；单纯切换焦点不会触发收起。若使用旧版Windows包，请查看[项目首页](../../README.md#下载与安装)的最新修复包 |
| 为什么任务不在“全部任务”里？ | 先清空搜索；已完成去“已完成”，删除项去“回收站”。“全部任务”默认显示未完成 |
| 移出今日后任务去哪了？ | 原任务在全部任务或已完成中，DDL 保留；有旧计划的未完成项可能回到“此前未完成” |
| 今日勾选后 DDL 列表也没了？ | 同一任务已完成，退出了 DDL 未完成列表；去已完成查看或撤销 |
| 有 DDL，为什么没有提醒？ | 当前只展示截止信息与逾期状态，尚无主动通知 |
| 数据备份按钮是灰色的 | 先处理任务或设置草稿，等正在进行的保存／恢复结束 |
| 任务或设置提示冲突 | 草稿仍在，先核对另一处的新状态，再明确确认要保存的修改 |
| 保存失败还能继续吗？ | 保留输入，查看错误并修复相应问题后重试；不要把仍存在的草稿当成已经落盘 |
| 两台电脑为什么不自动同步？ | 当前默认本地存储，无云同步；手动导入备份会替换目标机器任务集合，先备份并核对 |
| 浏览器预览中的任务为什么不在 App 里？ | 浏览器预览是独立演示数据，和原生 SQLite 不共用；实际使用请打开桌面 App |
| 下载链接失效或包被系统拦截 | 先检查产物到期与平台架构，再查看项目状态或提供完整系统提示给维护者 |

## 当前范围与反馈

已有 Mac arm64 App 和 Windows x64 安装包；当前仍为内部试用。Windows真实外点、隐藏草稿及两阶段退出已完成限定单屏复验；多屏／混合 DPI 真机仍未验证。完整系统手势、休眠／Spaces／虚拟桌面、长期试用和签名分发仍在完善。

当前不提供子任务、部分进度、重复任务、AI 规划、日历聚合、手机端、账号云同步、主动 DDL 提醒、全局快捷呼出或开机启动。设置中没有的选项不要按旧需求草案寻找。

反馈问题时，可通过[仓库 Issues](https://github.com/zhouchji-ops/Sidetask/issues)或与维护者现有的沟通渠道提供：应用版本／包名、系统与芯片架构、显示器数量和缩放、展开模式、重现步骤、预期与实际结果、完整错误文字。截图隐藏个人任务；不要公开上传个人数据库、备份或敏感正文。开发方式见[桌面客户端说明](../../apps/desktop/README.md)。
