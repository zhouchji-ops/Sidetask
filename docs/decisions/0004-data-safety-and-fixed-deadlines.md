# ADR-0004：试用阶段的数据安全、固定截止语义与退出保护

日期：2026-09-25。状态：接受实现；跨平台原生验收仍进行中。

## 背景与决定

阶段复查发现原型会向首次空库写demo、缺少升级安全备份、精确DDL随系统时区漂移；UI新任务草稿也不在退出保护内。按后续路线先补数据可靠性和失败闭环，不增加子任务、云同步或提醒。

1. schema2仍保留单一JSON快照表，仅加数据库身份和严格结构验证。schema1在一致性SQLite备份完成、校验并同步磁盘后事务升级；保留原JSON字节。规范化表暂后移，避免在未验证恢复链路前进行大规模模型重写。非SQLite、未知schema、异常结构、缺快照、非法关系拒绝覆盖。
2. 新用户空库无示例任务；浏览器演示仍用隔离合成数据。现有用户库不清空、不重置风格或任务。
3. 便携备份只含任务、计划及版本/导出时间；恢复先做完整SQLite安全备份，再事务替换任务/计划，保留设备设置和停靠。恢复前后修订号只增不减，并提升每个任务的revision，阻止旧编辑覆盖恢复数据。备份文件不提供可执行迁移SQL或任意路径能力。
4. 新建或实际修改DDL时固定IANA时区。日期型保留日历日，以该时区次日开始为逾期边界；精确型额外保存UTC瞬间。不存在或有歧义的本地精确时刻拒绝保存并保留草稿。旧无时区DDL保持原语义并给出提示；不能擅自猜测历史时区或重解释用户截止日期。
5. 显式退出由Rust发请求代次，唯一控制台收集所有任务/设置草稿，提供保存、放弃、取消。保存失败不批准退出；最终批准与在途事务协调。菜单、快捷键与系统退出路径须逐一验收，浏览器模拟不作为原生证据。
6. 设置提交与系统应用分开呈现。保存成功并不证明窗口生效；失败显示错误和重试入口，下一次成功应用再标记同步。

## 代价与边界

每次写入仍校验完整快照并检查可导出容量；这是早期可靠性选择，实际合成规模性能另记录。备份上限10MiB/10,000任务/100,000计划；超过时拒绝新提交，已有库不会截断。当前仍无周期备份轮转；损坏启动的图形恢复向导、真实断电演练和Windows验收未完成。
