# 侧笺 · SideTask 设计系统

更新时间：2026-09-25。当前实现是可交互的桌面原型；视觉与交互细节按正式产品持续打磨，不把原型等同于已完成商业发布验收。

## 设计方向

**让任务易于看见，让界面安静退后。** 默认纸笺用温暖纸白、深墨文字和克制的鼠尾草绿；另提供霜序、暖刊、极简三种完整视觉风格，让用户选择适合专注的氛围。控制台用于安排和编辑，边缘小窗用于一瞥和勾选，两者共享同一套排版、状态、按钮和颜色。

控制台使用稳定侧栏、薄工具栏和任务列表；不以统计图、巨大卡片或装饰插图挤占任务空间。品牌记号是原创的三行侧笺，右侧细线呼应屏幕边缘。图形由本地 SVG 和 Lucide 图标构成，不依赖网络字体或远程图片。

## 本轮精简基线（2026-09-25）

本轮在用户授权安装设计 skill 后，采用 Impeccable 的 Operate / distill 方法与 frontend-design 的场景审查。保留用户已选择的四套风格、霜序暖石灰色盘、双窗口结构和全部任务能力，调整任务与界面的主次。安装来源、许可与执行范围见 [设计 skill 记录](../docs/research/DESIGN_SKILLS.md)。

紧凑计划如下：色彩延续现有语义，系统字体承担任务与控件，页面和任务左对齐，主列表按行连续阅读。标题仅识别当前视图；今日日期保留，完成数放在列表标题行。删除装饰标签、口号、彩色句点、完成圆环、侧栏宣传卡及重复存储说明。小窗只留日期、任务区和操作；主题明暗用紧凑按钮选择。

这里的变化来自使用任务：看清一行任务及其 DDL，然后勾选或打开详情。强调色仍服务主操作与选中，间距用于分组，边框用于区分区域；避免给每条任务都加一层悬浮卡片。暖刊仍保留纸感，但展示字体只留在页面主标题。审美判断通过真实任务内容和大小窗截图复核，不能用换一套流行色代替结构改善。

## 四套风格与切换

| 标识 / 名称 | 视觉与排版 | 控件与密度 |
| --- | --- | --- |
| `paper` / 纸笺 | 纸白、鼠尾草绿，系统字体 | 平直列表、圆形勾选，默认方案 |
| `studio` / 霜序 | 暖石灰画布、炭黑侧栏、低饱和酒红强调 | 连续分组列表、柔和区域边角、方圆勾选；不逐行使用悬浮卡片 |
| `editorial` / 暖刊 | 奶油与赤陶，仅页面主标题用系统宋体、纸面横线 | 克制圆角；任务、详情、数量、表单与小窗统一使用系统无衬线字体 |
| `mono` / 极简 | 黑白灰、紧凑连续行，保留逾期语义色 | 4px边角、方形勾选、更窄侧栏，约58px任务行 |

每套具有独立浅色/深色 palette。风格与明暗模式正交，不改变任务语义与交互入口。设置首屏用四张含大小窗的示意卡呈现，按钮有完整可访问名称、选中状态及可见键盘焦点。点击即保存；持久化成功再更新，失败不伪装成功。不会覆盖其他设置草稿。明暗模式另用“浅色 / 深色 / 跟随系统”三个紧凑按钮选择，选中状态清楚可见；不再重复展示三张页面缩略图，仍按设置草稿规则保存。

[`STYLE_GALLERY.html`](STYLE_GALLERY.html) 展示合成数据的真实界面截图，可切换浅深色与大小窗对比；图像来自浏览器测试，并非原生窗口验收。补充调研见 [UI_REFERENCES](../docs/research/UI_REFERENCES.md)。

## 霜序配色修订（2026-09-25）

前轮按用户反馈移除原来的灰蓝配色。浅色：画布 `#f3f1ed`、纸面 `#fffefb`、侧栏 `#2b2826`、强调 `#7b4845`；深色：画布 `#221f1d`、纸面 `#2c2825`、强调 `#d9aaa0`。设置缩略卡、小窗、把手与阴影随色盘统一。本轮继续保留该色盘，任务区域改为连续分组列表。

界面评审以快速查看任务为基准，强调色主要服务操作和选中。配色变化不等于审美问题全部解决；本轮同时落实 [设计 skill 记录](../docs/research/DESIGN_SKILLS.md) 中的信息层级和结构精简方案。

## 色彩与字阶

基础组件与默认纸笺色彩在 [app.css](../apps/desktop/src/styles/app.css)，风格覆盖统一放在 [variants.css](../apps/desktop/src/styles/variants.css)，设置缩略卡在 [style-picker.css](../apps/desktop/src/styles/style-picker.css)。禁止在业务组件散布风格判断。暗色模式使用单独 token，不能简单反转界面。下表为默认纸笺。其浅色辅助文字使用 `#697168`，避免靠很浅的灰色制造精致感而牺牲可读性。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 / 纸面 | `#fcfcfa` | `#1b201d` |
| 详情与弹层 | `#ffffff` | `#222824` |
| 主文字 | `#272f2a` | `#e5eae0` |
| 辅助文字 | `#697168` | `#aab5a6` |
| 最弱文字 | `#697168` | `#879181` |
| 主色 | `#456b50` | `#88ad8c` |
| 高优先级 | `#926025` | `#d9b57c` |
| 逾期 / 错误 | `#b45140` | `#eea18e` |

使用系统字体栈：macOS 系统字体、Segoe UI、苹方、微软雅黑。纸笺 / 霜序页面标题 27 px，暖刊 30 px，极简 26 px；详情标题约 18 px，主列表任务标题 13–14 px，小窗任务标题 12 px，辅助信息不低于 11 px。暖刊只在页面主标题使用本机宋体族，其余文字继续使用系统无衬线。字体粗细以 400 / 500 / 600 为主；不依靠大量加粗制造层级。

颜色不能单独传递意义：完成同时有勾选和文字划线，高优先级有旗标及标签，错误有明确文案。

## 布局与密度

- 控制台侧栏默认 202 px，较窄窗口缩至 178 / 156 px。主内容使用流式宽度，上限 880 px；详情宽 304 px。
- 控制台页面标题、日期、列表标题与任务文字沿稳定的左侧轴线排列。完成数以列表标题行的文字显示，不另设圆环或统计卡。侧栏的小窗入口与其他工具入口保持同一操作层级，存储状态只在需要的位置说明。
- 常规任务行约 67 px；标题可按内容换行，不能把长标题截断到无法辨识。纸笺小窗行约 64 px，两个任务区独立滚动。小窗标题最多两行并保留全文 title / 可访问名称，点击查看完整详情，避免长标题淹没日期和勾选入口。
- 小于 780 px 的浏览器展示宽度，详情覆盖在内容右侧；桌面最小尺寸仍由原生窗口约束。
- 小窗默认 368 × 610 逻辑像素；允许 300–640 宽、380–1000 高，最终由原生层按所在显示器工作区进一步钳制。
- 各尺寸小窗均使用紧凑日期栏，不显示励志口号或装饰太阳；可用高度留给今日与 DDL 两区。最小尺寸也须容纳每区首项的摘要、勾选和元信息。
- 今日 / DDL 分隔线可拖动，比例范围 30–70%；提供方向键操作。
- 小窗内侧底角可以拖动外部宽高；左右停靠时抓手位置与横向增长方向对应。拖动以串行 IPC 预览尺寸，释放才提交设置。此期间保持交互锁，结束后释放。
- 原生面板的圆角、边框、阴影与输入区域保留在自身窗口范围内；浏览器的 drop-shadow 只是可视原型预览效果，不证明系统多屏边界通过。

## 交互约定

| 元件 | 行为 |
| --- | --- |
| 勾选圆点 | 更新同一任务状态；今日、DDL、控制台、小窗同步；提供撤销 |
| 任务正文 | 控制台打开详情；小窗定位控制台中的同一条任务 |
| 今日标签 | 表示计划引用，不能被误认为截止日期 |
| 新建任务 | 一个明确名称，可选备注、DDL、重要程度；可加入今日，无子任务 |
| 编辑草稿 | 显式保存；离开脏草稿提示；版本冲突保留输入并要求核对 |
| 设置草稿 | 仅提交用户改动字段，外部变更不会被整份旧设置覆盖 |
| 风格选择 | 即选即存，只提交 uiStyle；保留其他设置草稿，大小窗和把手同步，重启恢复 |
| Pin | 保持展开；不锁定位置 |
| 拖动把手 | 移动与换边；由原生窗口层负责监视器、DPI、最终停靠 |
| 关闭控制台 | 原生隐藏控制台；真正退出通过菜单栏 / 托盘 |

加载、空结果、已完成、错误和冲突都必须有真实状态界面。空状态告诉用户下一步动作；不使用虚假的统计或预填假成功提示。

## 界面文案

标题使用视图或动作名称，例如“今日”“任务详情”“新建任务”。任务完成反馈说明实际结果并保留“撤销”；空状态分别说明没有任务、没有截止日期或没有搜索结果，并指向对应的添加 / 调整操作。错误说明未完成的操作和重试方式，冲突继续保留草稿。移除“给自己一点留白”等励志表达、装饰性小标题和重复功能宣传，语气简短直接。

## 可访问性与注意力

所有图标操作有中文可访问名称，键盘焦点可见；模态框限制焦点并在关闭时恢复原焦点。Escape 遵守中文输入法组合状态；⌘ / Ctrl + N 新建，`/` 聚焦搜索。弹层输入通过交互锁防止误收起。

视觉过渡控制在 140–240 ms；遵守 `prefers-reduced-motion`。原生悬停只展示小窗，不主动夺取其他应用的键盘焦点。色彩对比、中文换行、最小尺寸、暗色模式需结合截图与真机持续检查。
